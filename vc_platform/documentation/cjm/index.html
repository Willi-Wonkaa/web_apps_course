CJM-деревья платформы Волонтёрского центра

Интерактивные карты пути пользователя (Customer Journey Maps) в виде n-арных деревьев. Каждый переход помечен оценочной эмоцией пользователя на этом шаге. Открывается по двойному клику из файла — интернет не нужен. Внутри дерева: тяни мышью — панорама, колесо или кнопки — зум, «Вписать» — вернуть общий вид. Точки зафиксированы.

Тим-лидер

Только свои мероприятия и пока меро не завершено: обработка заявок (в т.ч. по сменам), явка, часы, комментарии, доступ к профилям.

 полный доступ

Менеджер

Мероприятия (создание → публикация → рассылка → завершение), заявки и Excel-импорт, справочники, роли, отчёты.

 сквозная сущность

Мероприятие

Жизненный цикл от запроса извне до пост-обработки. В каждой стадии действуют разные роли (🔗).

Три точки первого касания (корни дерева волонтёра)

  1. Через бота — /start в Telegram, создаётся гость.
  2. Через подачу заявки на сайте — вход через Telegram, затем заявка (веб-регистрации «с нуля» нет).
  3. Через появление заявки из Excel — менеджер импортирует выгрузку; профиль создаётся автоматически, человек «встречает» систему позже.
