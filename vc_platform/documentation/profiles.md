# Типы профилей и уровни видимости (с визуальными примерами)

> Документ описывает **все виды профилей** в системе и то, что видит каждая роль.
> Источник правил: [reports.md](reports.md), [access-control.md](access-control.md), [db.md](db.md).
>
> Профиль — это не отдельная сущность, а **набор уровней видимости** над одной записью
> `users` (для волонтёра/ТЛ/менеджера). Кто именно смотрит — определяет, какие блоки видны.

---

## Уровни видимости

| Значок | Уровень | Кто видит |
|--------|---------|-----------|
| 👁 | Публичный | Все волонтёры |
| 👤 | Расширенный | Сам пользователь + менеджеры (тим-лидер — контекстно, правило 5 ACL) |
| 🔒 | Внутренний | Только менеджеры (тим-лидер — контекстно) |
| 👥 | Участник меро | Только участники конкретного мероприятия |

Профиль одного человека «складывается» из уровней в зависимости от смотрящего:
владелец видит 👁 + 👤; менеджер — 👁 + 👤 + 🔒; чужой волонтёр — только 👁.

## 1. Профиль волонтёра

### 👁 Публичный (видят все волонтёры)

```
┌─────────────────────────────────────────┐
│  @nickname                          ⭐   │  ← «Звёздочка», если season_hours ≥ порог ПГАС
│  ─────────────────────────────────────  │
│  Часов всего ........... 128            │
│  Мероприятий всего ..... 14             │
│  За сезон .............. 42 ч / 5 меро  │
│  ─────────────────────────────────────  │
│  Прошедшие мероприятия:                 │
│   • Забег «Осень»    12.10   6 ч        │
│   • Донор-день       28.09   4 ч        │
│   • …                                    │
└─────────────────────────────────────────┘
```

### 👤 Расширенный (сам пользователь + менеджеры; ТЛ — контекстно)

```
┌─────────────────────────────────────────┐
│  Иван Петров                 [Редактировать] │
│  ─────────────────────────────────────  │
│  Телефон ......... +7 900 000-00-00     │
│  Email ........... ivan@example.com     │
│  Telegram ........ @nickname            │
│  VK .............. vk.com/ivan          │
│  Дата рождения ... 14.03.2001 (24 г.)   │
│  Пол ............. мужской              │
│  ─────────────────────────────────────  │
│  История заявок:                        │
│   • Забег «Осень»   подана 01.10  ✅    │
│   • Форум           подана 20.09  🕓    │
│  Любимые категории: Спорт · Экология    │
└─────────────────────────────────────────┘
```

> ⚠️ Благодарственные письма в расширенном профиле **не показываются** — они доступны
> только в апп/на сайте, в карточке соответствующего мероприятия (участнику).
> Личные данные (ФИО, номер, username, email, VK, о себе, ДР) владелец может
> **редактировать** сам (см. web V10).

### 🔒 Внутренний (только менеджеры; ТЛ — контекстно по правилу 5)

```
┌─────────────────────────────────────────┐
│  🔒 Внутреннее — Иван Петров            │
│  ─────────────────────────────────────  │
│  Статус .............. active           │
│  Churn score ......... 1.0              │
│  Регистрация ......... 12.01.2025       │
│  Последнее участие ... 12.10.2025       │
│  Исключения из треб. . 18+ (причина: …) │
│  Активные заявки ..... Форум (🕓 new)   │
│  Конверсия заявок .... 71%              │
│  Комментарии (ТЛ/мен): «пунктуальный»   │
│  История churn ....... сезон 24/25: 2.0 │
└─────────────────────────────────────────┘
```

> Волонтёр **никогда** не видит свой внутренний профиль и комментарии к себе.

## 2. Профиль тим-лидера

Всё из профиля волонтёра (👁 + 👤 + 🔒), плюс доп. поля ТЛ — они **публичны** (👁).
Отдельного внутреннего профиля у ТЛ нет.

### 👁 Дополнительно к публичному

```
┌─────────────────────────────────────────┐
│  @nickname                    [Тим-лидер] │
│  … (обычный публичный профиль) …        │
│  ─────────────────────────────────────  │
│  Меро как тим-лидер (всего) ... 9       │
│  Меро как тим-лидер (сезон) ... 3       │
│  Назначен ТЛ с ............... 05.02.2025 │
└─────────────────────────────────────────┘
```

## 3. Профиль менеджера

### 👁 Публичный

```
┌─────────────────────────────────────────┐
│  Мария Иванова               [Менеджер] │
└─────────────────────────────────────────┘
```
Только ФИО.

### 🔒 Внутренний (только менеджеры)

```

│  🔒 Мария Иванова — менеджер            │
│  ─────────────────────────────────────  │
│  Контакты ......... +7 …, @maria, email │
│  Назначена ........ 01.09.2024          │
│  Кто назначил ..... Пётр Сидоров        │
│  Обработано заявок  312 (всего) / 88 (сезон) │
│  Ср. время обработки  4 ч 12 мин        │
│  Меро под управл. .. 6 сейчас / 40 всего │
└─────────────────────────────────────────┘
```

## 4. Карточка мероприятия (профиль меро)

Мероприятие тоже имеет уровни видимости.

### 👁 Публичная (все волонтёры)

```
┌─────────────────────────────────────────┐
│  Забег «Осень»              [Набор open] │
│  ─────────────────────────────────────  │
│  📅 12.10.2025  09:00–15:00             │
│  📍 Парк Победы                         │
│  🏢 ГБУ «Спорт»                         │
│  🏷 Спорт · Городские события           │
│  Требования: 18+                        │
│  Тим-лидер: @lead                       │
│  🔗 Чат · Пост в канале                 │
│  Помогли людям: 1 200                   │
└─────────────────────────────────────────┘
```

### 👥 Расширенная (участникам меро)

```
┌─────────────────────────────────────────┐
│  … публичная карточка …                 │
│  ─────────────────────────────────────  │
│  Волонтёров на меро .... 25             │
│  🔗 Чат мероприятия                     │
│  🔗 Добро.ру                            │
│  Рейтинг меро .......... 8.6 / 10       │
│  📄 Благодарственное письмо  [Скачать]  │  ← только тут, не в профиле
│  [ Оценить мероприятие ]                │
└─────────────────────────────────────────┘
```

### 🔒 Внутренняя (менеджеры; ТЛ — по своим меро)

```
┌─────────────────────────────────────────┐
│  🔒 Забег «Осень» — набор               │
│  ─────────────────────────────────────  │
│  Нужно .... 30    Есть .... 22    Осталось .. 8 │
│  Подано заявок ......... 41             │
│  Контакты команды: менеджер, ТЛ         │
│  Организатор: ФИО, ☎ +7 …, ✈ @org       │
│  Заявки: список ФИО/тел/статус + фильтры │
│  Добро.ру: часы проставлены (кем)       │
│  Внутренние комментарии по организации  │
│  Шаблон письма: «Благодарность 2025»    │
└─────────────────────────────────────────┘
```

## 5. Карточки организации и организатора

Полностью внутренние (🔒), видят только менеджеры (организацию — ещё и ТЛ по своим меро).

### 🔒 Организация

```
┌─────────────────────────────────────────┐
│  🔒 ГБУ «Спорт»                         │
│  Описание деятельности …                │
│  Меро: 40   Волонтёров: 350   Смен: 900 │
│  Категории: Спорт · Здоровье            │
│  Организаторы: Пётр (☎, ✈)              │
│  Внутр. оценка: 9/10                    │
│  Комментарии менеджеров/ТЛ …            │
└─────────────────────────────────────────┘
```

### 🔒 Организатор (контактное лицо)

```
┌─────────────────────────────────────────┐
│  🔒 Пётр Сидоров                        │
│  Организации: ГБУ «Спорт», …            │
│  Меро как контакт: 18                   │
│  ☎ +7 …  ✉ …  ✈ @petr  VK  WhatsApp     │
│  Комментарии менеджеров …               │
│  История взаимодействия: звонки/встречи │
└─────────────────────────────────────────┘
```

## Сводка: кто какой профиль видит

| Профиль | Волонтёр (чужой) | Владелец | Тим-лидер | Менеджер |
|---------|------------------|----------|-----------|----------|
| Волонтёр — 👁 | ✓ | ✓ | ✓ | ✓ |
| Волонтёр — 👤 | ✗ | ✓ (свой) | контекстно | ✓ |
| Волонтёр — 🔒 | ✗ | ✗ | контекстно | ✓ |
| Доп. поля ТЛ — 👁 | ✓ | ✓ | ✓ | ✓ |
| Менеджер — 👁 (ФИО) | ✓ | ✓ | ✓ | ✓ |
| Менеджер — 🔒 | ✗ | — | ✗ | ✓ |
| Меро — 👁 | ✓ | ✓ | ✓ | ✓ |
| Меро — 👥 | если участвовал | если участвовал | ✓ | ✓ |
| Меро — 🔒 | ✗ | ✗ | по своим меро | ✓ |
| Организация / организатор — 🔒 | ✗ | ✗ | орг. по своим меро | ✓ |

> «Контекстно» для ТЛ — правило 5 в [access-control.md](access-control.md): своё меро,
> оно не завершено, волонтёр связан с ним (подал заявку/участвует).
